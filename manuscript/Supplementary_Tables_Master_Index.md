# Supplementary Information — Master Index of Empirical Data Tables and Source Data (`Table S1`–`Table S5i`)

**Manuscript:** *Dynamic single-cell niche remodeling and biophysical steric exclusion govern clinical trial attrition across human organs*

All quantitative statistics, odds ratios, receiver operating characteristic (ROC) curves, calibration deciles, Decision Curve Analysis (DCA) trajectories, profile-likelihood scans, spatial proximity matrices, and patient-level responder predictions reported in the Main Text, Main Tables 1–2, Extended Data Table 1, Main Figures 1–5, and Extended Data Figures 1–4 trace deterministically to the 52 empirical CSV, NPZ, and JSON source-data files archived in `outputs/stage2_tables/`. No synthetic or simulated clinical trial records or transcriptomic counts are included anywhere in this archive.
